# Affiches LinkedIn

Visuels générés en code (HTML/CSS rendu par Playwright en 2x), à partir de vraies captures de l'app.

| Fichier | Format |
|---|---|
| `bankcards-affiche-1080x1350.png` | affiche principale, 4:5 |
| `bankcards-banniere-1200x627.png` | bannière paysage |
| `bankcards-carrousel-01.png` … `05.png` | carrousel, 4:5 |
| `bankcards-carrousel-linkedin.pdf` | carrousel en document PDF (5 pages) |

Pour les régénérer : `python3 posters/src/build.py`.
